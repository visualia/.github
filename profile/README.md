# Visualia

Interactive learning in the browser.

- **[visualia](https://github.com/visualia/visualia)**: the current Visualia
  (2026 onward), a shared canvas and studio for learning and making with AI.
- **[visualia_original](https://github.com/visualia/visualia_original)**: the
  original JavaScript framework for interactive learning experiences
  (2020–2022, archived). Docs: https://visualia.github.io/visualia_original/
- **[visualia_history](https://github.com/visualia/visualia_history)**: every
  other 2020–2022 Visualia repo in one archive, with full history and branches.
